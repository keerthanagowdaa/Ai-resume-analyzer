# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer that evaluates resumes against job descriptions using Natural Language Processing (NLP) and Machine Learning techniques.

---

## 📖 Project Overview

The AI Resume Analyzer helps job seekers optimize their resumes by analyzing skills, keywords, ATS compatibility, and matching resumes with job descriptions.

The application provides actionable insights to improve resume quality and increase interview chances.

---
